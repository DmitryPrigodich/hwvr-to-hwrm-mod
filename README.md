# Vast Reaches → Homeworld Remastered

Локальный прототип переноса ресурсов установленной Steam-демки Vast Reaches.

## Текущее состояние

- Две расы для скирмиша: **Новокушане** и **Радаа**.
- У 15 Новокушан с прямым кушанским аналогом подключены его штатные иконки HWRM.
  В демке отдельные рисунки меню строительства найдены только для шести типов;
  большинство записей использует `SPR_UI_Icon_X`. Иконки Радаа пока не настроены.
- **39 импортированных типов в строительстве:** 20 у Новокушан, 19 у Радаа.
- **72 экспоната на карте осмотра**, сгруппированные по фракциям и классам.
  У 36 экспонатов есть штатный аналог справа; всего в сцене 108 кораблей и объектов.
  Между аналогами оставлена ширина корпуса, между соседними парами — сумма
  ширин соседних корпусов, между классами — длина большего корпуса.
  Расстановка учитывает габариты всех LOD; увеличение с расстоянием отключено.
- Исходные UV, текстуры, имеющиеся уровни детализации и составные части моделей.
- Массивы Texture2DArray секций станции и материнского корабля читаются по
  исходному индексу слоя. У двери пустой материал дальних LOD заменён её атласом.
- Штатная дверь HWRM выделена из реального меша материнского корабля и показана
  рядом с VR-дверью. Датчик и повреждённый эсминец также имеют штатные сравнения.
- Карты нормалей, блеска/отражения, свечения и окраски, с привязкой к материалам Unity.
- Уникальные имена встроенных текстур и материалов: разные корабли больше не
  используют общие имена `hull_DIFF` / `hull_NORM` и `Hull`.
- Сжатие DXT1 для непрозрачных материалов, DXT5 для прозрачной сферы щита.
  Исходное разрешение текстур сохранено, включая карты окружения 4096×4096.

Параметры, оружие и возможности адаптированы из HWRM. Это временные игровые
прототипы, а не восстановленный баланс Vast Reaches. Исходная геометрия не
дорисовывалась. Преобразование освещения Unity в HWRM приближённое.

## Запуск и осмотр

`launch_test.ps1 -Gallery` открывает общую карту.

| Клавиша | Действие |
| --- | --- |
| F1 / F2 / F3 / F4 | Новокушане / Радаа / NPC / MISC |
| 1–7, верхний ряд | Обзор класса выбранной фракции |
| N / P | Следующая / предыдущая отдельная пара или модель |
| PgDown / PgUp | Следующая / предыдущая группа |
| 8 | Обзор текущей фракции |
| 9 | Первая пара текущего класса |
| 0 | Общий вид карты |

У сравнительных пар слева VR, справа штатный HWRM. Остальные экспонаты стоят
отдельно. Камера свободна для вращения и приближения, стрельба в сцене отключена.
Список всех экспонатов по порядку — в [GALLERY.md](GALLERY.md).

`launch_test.ps1` открывает обычное меню мода. В новом скирмише выбрать Новокушан
или Радаа. Новые записи строительства имеют пометку VR; штатные списки пока
сохранены. Исследования и подсистемы для новых записей не требуются.
Старые сохранения не получают новый состав стартового флота автоматически.

`launch_test.ps1 -Compare` оставлен для отдельной сцены только восьми пар.
`launch_test.ps1 -Scene` — изолированная боевая проверка 13 импортированных типов.

При обычном запуске через Steam требуется параметр `-mod VastReachesDemo.big`.
Подготовленные скрипты передают его сами. Мод установлен отдельным архивом
`HomeworldRM/Data/VastReachesDemo.big`; исходные архивы игры не заменяются.

## Флоты и ограничения

Полный состав и выбранные прототипы — в [FLEETS.md](FLEETS.md).
В стартовом флоте Новокушан используются перенесённые материнский корабль,
носитель и сборщики. У Радаа перенесён носитель; флагман и сборщики пока штатные.
Отдельная конфигурация материнского корабля Радаа в восстановленном наборе не найдена.

У дополнительных кораблей маркеры и пути стыковки заимствованы из выбранного
прототипа HWRM, с сохранением новых мешей, материалов и коллизии. У трёх эсминцев
отдельные чужие орудийные подсистемы удалены; стрельба перенесена на исходные
точки VR. Баррикадный фрегат оставлен без оружия, как в конфигурации демки.
Дальнейшая подгонка нужна там, где геометрия отличается. Исходные светящиеся
текстуры двигателей перенесены; отдельные эффекты выхлопа новых кораблей ещё
требуют настройки. Анимация створок, подвижных деталей и специальные механики
Unity пока не восстановлены. Створка материнского корабля показана отдельно.
У Радаа многопушечный корвет, штурмовой фрегат и эсминец используют таииданские
корпуса сравнения и основы характеристик. Внутренний ID корвета
`rad_missilecorvette` сохранён для совместимости, видимое имя исправлено.
Баллистический эсминец имеет одну исходную ракетную установку, сейчас с
временным оружием HWRM `Hgn_DestroyerTorpedoLauncher`; пушечных турелей у него нет.

У первой восьмёрки сохраняются известные ограничения ранней боевой обвязки:
время строительства малых кораблей взято от всей штатной группы, а у
бомбардировщиков подключён один основной оружейный узел. Захват и ремонт
этих восьми типов отключены до подготовки соответствующих точек.

Бентуси, станции, обломки, астероиды, ракета и сфера щита служат для осмотра.
Невидимые коллизионные помощники в экспозицию не входят. Сфера статически
воспроизводит сетку и цвета исходного материала; динамический эффект Unity
не перенесён. Кампания, звук и постановочные сцены — отдельный дальнейший этап.
Набор демки не доказывает полноту ресурсов всей игры.

## Сборка и проверки

`rebuild_test.ps1` собирает определения и архив из подготовленных моделей.
`-Models` повторно извлекает первую восьмёрку; `-Catalogue` извлекает остальные
модели; `-Recover` обновляет определения Unity. Для продолжения сборки каталога
есть `tools/export_catalogue.py --resume`; для ремонта отдельных объектов —
повторяемый аргумент `--only <id>`.

После сборки: `install_test.ps1`, затем нужный вариант `launch_test.ps1`.
Перед установкой и повторным запуском текущую игру нужно закрыть.

- `tools/verify_gallery.py --live` проверяет имена текстур, форматы сжатия,
  заимствованную обвязку, записи строительства и загрузку всех экспонатов по логу.
- `tools/verify_fleet_materials.py` проверяет материалы, LOD и исходные узлы первой восьмёрки.
- `tools/verify_physical_gallery.py` проверяет интервалы, отсутствие пересечений,
  масштаб, материалы секций и совпадение выделенной двери с оригинальным мешем HWRM.
- `tools/verify_combat.py` измеряет урон 13 типов по здоровью отдельных мишеней,
  включая три эсминца и два корабля Радаа с исправленной таииданской основой.
  Загрузка HOD сама по себе не считается проверкой работы оружия.
- `local/gallery-verification.json`, `local/fleet-material-verification.json` — отчёты.
- `local/HWRM-test.log` — последний игровой запуск; архив дополнительно проходит CRC.

Захват окна OpenGL через computer-use не сработал. Проверки загрузки и структуры
не подменяют визуальную оценку в самой игре. Боевая проверка первой восьмёрки
сохраняется отдельно в `local/HWRM-combat-passed.log`.

## Исходные данные и инструменты

Unity 2021.3.38f1, Python 3.12, UnityPy из локального `.venv`.
Официальный Steam Toolkit: HODOR и Archive.exe. Blender для этого конвертера не требуется.
Из демки восстановлены 104 определения и 41 иерархия игровых моделей, включая варианты состояний.
Дополнительные модели и окружение извлекаются по фактическим ссылкам MeshRenderer → Material → Texture.
Все извлечённые игровые данные, модели, архивы и окружение Python исключены из Git.
