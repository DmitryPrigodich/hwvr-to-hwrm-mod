## Как поддерживаем документы

Текущий RU собирается из `localization/ru/{early,late,shared}.json`. После правки запускаем `tools/sync_campaign_documents.py`: он обновляет сценарии и HTML, синхронизирует RU-блоки разборов, сохраняя ручные заметки. С `--check` только проверяет соответствие. Установка мода — отдельное действие.

[Архив и прежние инструкции](archive/README.md) убраны из основного маршрута. Буквальный EN и старая русская локализация сохранены. [Git и состав репозитория](GIT_REPOSITORY.md).
