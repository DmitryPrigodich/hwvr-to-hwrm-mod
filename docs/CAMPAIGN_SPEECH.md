## Как сделано в оригинале

- `local/hwrm-base/scripts/scar/scar_util.lua:9`: `HW2_SubTitleEvent` вызывает `Subtitle_Add(actor,text,time)` и ждёт `Subtitle_IsDone(actor)`. В HW2 M01 это обычная очередь реплик FleetCommand/FleetIntel.
- `ui/subtitle.lua` определяет темы персонажей через `addTheme`, а `addRegion(1,...)` связывает верхний текст с портретом. В оригинале явно выделены свободные слоты27–31 для модов. Штатные картинки384×192; существующие темы0–26 оставлены без изменений. Числовое значение Actor_FleetCommand=1 дополнительно проверено по константе установленного EXE, без запуска/модификации EXE.
- Родное обучение задаёт `Sound_SpeechSubtitlePath("speech:missions/TUT_01/")`; у TUT_03 также сохранён образец пути через `data:sound/speech/...`. WAV называется номером UCS. Извлечённые оригинальные WAV — PCM mono16bit44100Hz.
- `local/hw2campaign/animatics/a00.lua` подключает `speechFilename`; `locale/russian/animatics/a00_speech.lua` вызывает `SetSpeechFolder` и `AddSpeechEvent`. В EnglishSpeechHW2Campaign.big у каждого WAV есть соседний Lua с version4/compression0/volume/randSampContainer. Наши конечные PCM тоже имеют такие описания.

## Зацикливание речи ролика

В WebM оставлены изображение, музыка и окружение. **Голоса из WebM удалены**;125 речевых событий12 сцен вынесены в `AddSpeechEvent` с исходными моментами запуска. `speechFilename` указывает на локализованное описание `VRE_*_speech.lua`, которое выбирает отдельные PCM по исходным ключам. Нижние RU/EN-субтитры пока вшиты в изображение; новые актёры нужны для разговоров во время самой миссии.

Причина повтора в прежнем встроенном потоке Vorbis точно не установлена. Наш WebM и штатный animatic_03-04 используют VP8/Vorbis44100Hz, поэтому смена частоты наугад не выдана за исправление. Теперь речь идёт отдельным штатным путём; пролог новой версии пользователь подтвердил в игре. Это не устанавливает причину старого дефекта. Музыкальный микс выбранный1/0,28/0,35 по исходной подготовке: голос теперь обрабатывается своим звуковым описанием(volume0,85), в WebM только0,28музыка/0,35окружение.

## Воспроизведение подготовки

`tools/campaign_speech.py` готовит отдельный `local/campaign-speech/source` поверх cinematic seed, PCM/темы/таймлайны и видео без голоса. `verify_campaign_speech.py` проверяет ресурсы/очередь; `--scripts-only` повторяет только код/PCM/хеши, сохраняя предыдущий полный видеотест. `build_fleet_preview.py` учитывает включённый speech-этап; упаковщик берёт финальные Movies из `local/campaign-speech/release-movies`. Для текущего установленного пакета проверять именно этот source, а не старый seed `local/cinematic-update/source`.

Канонические mini-скрипты также обновлены. Не запускать обычный campaign-only rebuild поверх совмещённой пробы флотов. Полное старое `apply_campaign_movies` без нового speech-этапа может вернуть встроенный голос; после его использования снова выполнить speech-подготовку. Все исходные полные WebM с голосом сохранены в старом `local/cinematic-update/movies`; они не удалялись.

Отчёты: `local/campaign-speech/{integration,verification,verification-scripts,installation,installation-verification}.json`, исходный журнал перед обновлением — `native-before-update.log`. Код в GitHub, медиа по-прежнему исключены из Git.
