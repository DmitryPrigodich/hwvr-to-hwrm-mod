# Компактная карта сравнения HWVR / HWRM

`launch_test.ps1 -Gallery`. В парах HWVR слева, штатный HWRM справа. Автоувеличение с расстоянием отключено.

Между аналогами — ширина большего корпуса; между соседними парами — сумма ширин соседних корпусов; между классами — длина большего корпуса. Совпадающие модели приведены к масштабу HWRM без растягивания по осям.

F1 — Новокушане; F2 — Радаа; F3 — NPC; F4 — MISC.

1–7 — обзор класса текущей фракции; N/P — отдельные пары; PgUp/PgDn — следующий/предыдущий класс. 8 — обзор фракции; 9 — первая пара текущего класса; 0 — вся карта.
