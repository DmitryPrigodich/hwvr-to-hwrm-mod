# Vast Reaches — сборка обучения для показа,24октября2026

По уточнению Дмитрия «первая миссия» здесь означает **пролог и M0. Обучение**, не M01 «Хиигара». Это отдельный пакет; основная кампания и её установленная версия не продвигаются этой командой.

## Как передать и запустить

- Архив: `local/VastReaches-Tutorial-2026-10-24.zip` (239453736байт, около228.4МиБ).
- Распакованная папка: `local/VastReachesTutorial-release`.
- Распаковать ZIP целиком → запустить **Play Tutorial.cmd**.
- В игре: **Extra Missions → Vast Reaches: Обучение → M0. Обучение**. Начать новую миссию; перед ней идёт пролог.
- **Play Tutorial English.cmd** выбирает EN; **Install only.cmd** устанавливает без запуска. По умолчанию окно1600×900.
- Нужна Steam Homeworld Remastered Collection; Python/Toolkit/отдельная установка зависимых модов не нужны. Если запись в папку Steam запрещена, Install only.cmd один раз запускается от администратора, затем Play Tutorial.cmd — обычно.

Установщик ищет Steam-библиотеки и при необходимости спрашивает папку Homeworld. Его собственные пути: `HomeworldRM/DataWorkshopMODs/VastReachesTutorial` и `HomeworldRM/Data/Animatics/VastReachesTutorial`. Они отличаются от главного установленного пакета. Неизвестные папки не перезаписываются; прежняя версия только этого показа сохраняется вне игры в `%LOCALAPPDATA%/VastReachesTutorial/backups`. Одинаковая версия повторно не копируется. При работающей игре из выбранной папки установка останавливается.

## Содержание

Единственная доступная глава — T01_Training. Сохранены34реплики, оригинальные EN-голоса, текущий RU/EN, портреты, музыка The Beginning, фон Хиигары ez16, один полный отряд, дальний разведчик, вэйпойнты W через A/B, повторяемый безопасный сброс, финальная атака и разговор о прыжке. Строительства нет. M01/M04 и проба флотов не предлагаются в этом меню. Внешние ролики остальных глав не включены; только две языковые версии пролога. Полный код кампании не переписывается.

Слои скомпонованы в один основной BIG плюс языковые Russian.big/English.big. Это композиция исходников с закреплёнными зависимостями, не произвольный стек BIG.

## Воспроизведение и границы проверки

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/build_mod_layers.py --package-candidate
.\.venv\Scripts\python.exe -X utf8 tools/build_tutorial_showcase.py
.\.venv\Scripts\python.exe -X utf8 tools/verify_tutorial_showcase.py
```

Генератор показа читает уже проверенный закреплённый layered source, сверяет все входные хеши, копирует его в собственный короткий каталог и проверяет неизменность унаследованных кораблей/оружия/рас/науки. Изменения профиля: одно обучение в меню, его миниатюра/заголовок, отдельный путь ролика и исключение неиспользуемых внешних вступлений. Сам учебный сценарий не менялся.

Проверены: полная распаковка и сверка содержимого трёх BIG, допустимые alias data/locale, входной сценарный baseline, инициализация M0 и переход от разговора к сенсорам/камере, SHA256 всех14вложенных файлов, ZIP CRC. Windows PowerShell5.1 проверен на фиктивной игре: RU/EN/оконный план, установка, идемпотентность, отказ заменить чужую папку, backup своей версии вне фиктивной игры и сохранность соседнего мода. Фиктивный EXE не выполняется. Это **не нативная проверка запуска или прохождения HWRM**. Пакет не установлен в настоящую игру, игра не запускалась этим заданием.

Отчёты: `local/tutorial-showcase/release.json`, `handoff-verification.json`, `input-source.json`, `package-logs/`.
