# Репозиторий кода мода

Локальный Git находится в корне проекта. Удалённый сервер не настроен,
публикация и отправка файлов не выполнялись.

В историю входят инструменты Python, запускатели/установщик, сценарии Lua,
карты и определения мода, локализация, проектные документы и снимок текущего
кода флотов в `fleet-preview/`. Подготовленные сценарии полной кампании
сохраняются в `campaign-export/data/`; это всё ещё экспериментальная основа.

Из истории исключены модели и геометрия, текстуры, изображения, звуки, видео,
BIG/ZIP/APK/OBB, извлечённые исходники игр, инструменты EXE/DLL, окружение
Python и рабочие/резервные каталоги `local/`, `exports/`.
Игровые файлы на диске остаются на месте. Репозиторий кода сам по себе
не заменяет установленную игру и локальную подготовку ресурсов.

После изменения сгенерированного флота обновить снимок:

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/snapshot_fleet_code.py
```

Ветка: `codex/homeworld-vast-reaches`, первый коммит `51371ed`. В активном Git только достижимая история кода. Старые неиспользуемые бинарные данные прежней пустой .git сохранены отдельно в `local/git-history-backups`; в активную историю не входят.
